キー操作

閉じるEsc

Windows 版との違い

  • エクスプローラーは模型です。ブラウザからは本物のエクスプローラーやファイルを開けないため、画面の中の模型が移動します。Windows 版では直前に使っていたエクスプローラー (タブ) がその場で移動し、ファイルは Excel などで開きます。
  • 検索の中身は同じです。並び順の計算、全角/半角・ひらがな/カタカナの同一視、「よく使う」の学習、Tab での絞り込みは Windows 版のコードをそのまま移植しています。模型のエクスプローラーで開いたフォルダも「よく使う」に学習されます。
  • 「自分のフォルダで試す」で選んだフォルダの中身は、このページの中だけで処理されます。どこにも送信されません。ブラウザの仕様で、空のフォルダは読み込まれません。
  • 最初から入っている「ピン留め」「よく使う」はデモ用の例です。デモで付けたピンや履歴はこのブラウザにだけ保存されます。
