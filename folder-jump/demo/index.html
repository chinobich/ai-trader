Windows 版との違い

  • エクスプローラーは模型です。ブラウザからは本物のエクスプローラーやファイルを開けないため、画面の中の模型が移動します。Windows 版では直前に使っていたエクスプローラー (タブ) がその場で移動し、ファイルは Excel などで開きます。
  • 「名前を付けて保存」も模型です。Windows 版では Excel・Word・PDF ソフトなど、Windows 標準の保存画面や「開く」画面ならどれでも使えます。もともと入っていたファイル名はそのまま残ります。
  • 検索の中身は同じです。並び順の計算、全角/半角・ひらがな/カタカナの同一視、表記ゆれ辞書と和暦、拡張子や更新日の絞り込み、「よく使う」の学習、Tab での絞り込みは Windows 版のコードをそのまま移植しています。模型のエクスプローラーで開いたフォルダも「よく使う」に学習されます。
  • 「自分のフォルダで試す」で選んだフォルダの中身は、このページの中だけで処理されます。どこにも送信されません。ブラウザの仕様で、空のフォルダは読み込まれません。
  • 最初から入っている「ピン留め」「よく使う」はデモ用の例です。デモで付けたピンや履歴、見た目の設定はこのブラウザにだけ保存されます。
