# FolderJump

ファイルサーバーの奥深くにあるフォルダやファイルへ、キーボードで一瞬で飛ぶための Windows 11 用ランチャーです。

`Ctrl` + `Alt` + `Space` で呼び出して名前の一部を入力し、`Enter` を押すと、いま使っているエクスプローラーがその場所へ移動します。

- **インストール不要・管理者権限不要**: Windows に最初から入っている C# コンパイラでビルドします
- **ファイルサーバーの中身はローカルにインデックス化**: 毎回サーバーを探しに行かないので、数十万件あっても一瞬で絞り込めます
- **Mac でも動作を確認できます**: ブラウザで動くデモ（`demo/index.html`）を同梱しています

---

## 目的の場所に早くたどり着くためのアイデア

「フォルダが深くて複雑」「どこにあるか覚えていない」問題への対策を、手軽なものから順に並べました。FolderJump は 4〜7 をまとめて実現しています。

| # | アイデア | 効果 | FolderJump |
|---|---|---|---|
| 1 | エクスプローラーの「クイックアクセスにピン留め」 | よく行く場所を左側に固定できる | — |
| 2 | アドレスバーにパスを直接入力・貼り付け (`Alt`+`D`) | パスが分かっていれば一発で移動できる | パスの貼り付けに対応 |
| 3 | 共有フォルダをネットワークドライブ (Z: など) に割り当てる | パスが短くなる | Z:\ も検索対象にできる |
| 4 | **名前の一部で横断検索する** | 場所を覚えていなくても探せる。Windows 標準の検索は共有フォルダだと遅い | ローカルのインデックスで瞬時に検索 |
| 5 | **よく使う場所を学習して上位に出す** | 使うほど速くなる | 開いた回数と最近使ったかどうかで順位を上げる |
| 6 | **親フォルダの名前でも絞り込む** | 「2024 見積」のように、覚えている断片を組み合わせて探せる | スペース区切りで AND 検索 |
| 7 | **キーボードだけで階層をたどる** | マウスで何度もダブルクリックしなくて済む | `Tab` で中へ、`Backspace` で上へ |

> 会社のルールで自作ソフトが使えない場合は、1〜3 だけでもかなり楽になります。

## 使い方

### 1. ビルドする（最初の 1 回だけ）

1. このフォルダ（`folder-jump`）を Windows 11 の PC にコピーします
2. `build.bat` をダブルクリックします
3. `FolderJump.exe` ができます（数秒で終わります）

> ダウンロードした ZIP から展開した場合、`build.bat` の実行時に「Windows によって PC が保護されました」と出ることがあります。その場合は「詳細情報」→「実行」を選ぶか、展開する前に ZIP を右クリック →「プロパティ」→「許可する」にチェックを入れてください。

### 2. 起動して検索対象を登録する

1. `FolderJump.exe` をダブルクリックします（タスクトレイに常駐します）
2. エクスプローラーでファイルサーバーの共有フォルダを開き、アドレスバーのパス（例: `\\fileserver\share`）をコピーします
3. FolderJump の入力欄に貼り付け、「このフォルダを検索対象に追加」を選んで `Enter` を押します
4. スキャンが始まります。スキャン中でも、見つかったものから順に検索できます

`>` と入力すると「Windows 起動時に自動で起動する」などのコマンドが出ます。

### 3. キー操作

| 操作 | キー |
|---|---|
| 呼び出す / 閉じる | `Ctrl` + `Alt` + `Space` / `Esc` |
| 開く | `Enter`（直前のエクスプローラーやタブがその場で移動します。ファイルはアプリで開きます） |
| 場所を開く | `Shift` + `Enter`（そのファイルを選択した状態でフォルダを開きます） |
| 新しいウィンドウで開く | `Ctrl` + `Enter` |
| フォルダの中へ / 上へ | `Tab` / `Shift` + `Tab`。入力欄が空なら `Backspace`、`→` / `←` も使えます |
| ピン留め | `Ctrl` + `D`（何も入力していない時に一番上に並びます） |
| パスをコピー | `Ctrl` + `C`（同僚にパスを送る時に便利です） |
| コマンド | `>` を入力 |

### 4. 検索のコツ

- `見積 2024` → 「2024」フォルダの中の「見積」を含むもの（スペース区切りで AND 検索。親フォルダ名も対象）
- `みつもり` → 「ミツモリ」にも一致（ひらがなとカタカナ、全角と半角、大文字と小文字の違いは無視します）
- `議事録 -旧` → 「旧」を含むものを除外
- `\\fileserver\share\営業\…` → メールで届いたパスを貼り付けて、そのまま開く

## 設定

`>` →「設定ファイルを開く」で `FolderJump.ini` がメモ帳で開きます。保存すると自動で反映されます。

| 項目 | 既定値 | 説明 |
|---|---|---|
| `Hotkey` | `Ctrl+Alt+Space` | 呼び出しキー。例: `Ctrl+Shift+J`、`Alt+Q` |
| `IncludeFiles` | `true` | ファイルも検索対象にする（`false` にするとフォルダだけになり、軽くなります） |
| `SkipHidden` | `true` | 隠しファイル・隠しフォルダを無視する |
| `FollowLinks` | `false` | ジャンクションやシンボリックリンクの中までたどる（無限ループを防ぐため既定は無効） |
| `RescanHours` | `12` | インデックスを自動で作り直す間隔（時間） |
| `ScanThreads` | `8` | スキャンの同時実行数。サーバーの負荷が気になる場合は小さくします |
| `MaxEntries` | `3000000` | インデックスに入れる最大件数（100 万件でメモリ約 150MB が目安） |
| `ReuseExplorer` | `true` | 直前に使っていたエクスプローラーのウィンドウ（タブ）をそのまま移動させる |
| `LearnFromExplorer` | `true` | エクスプローラーで普通に開いたフォルダも「よく使う」として学習する |
| `[Roots]` | — | 検索対象のフォルダ（1 行に 1 つ） |
| `[Exclude]` | ごみ箱・スナップショット・Office の一時ファイルなど | スキャンしない名前（`*` と `?` が使えます） |

設定・履歴・インデックスはすべて `%LOCALAPPDATA%\FolderJump` に保存されます。外部への送信は一切ありません。

## 仕組み

```
ファイルサーバー ──(並列スキャン・定期的に)──▶ インデックス (ローカルのメモリ + ファイル)
                                                    │
 Ctrl+Alt+Space ─▶ 入力 ─▶ 検索 (キー入力ごと, 100 万件で約 50ms) ─▶ 結果
                                                    │
                                     よく使う順の学習 ◀─ 開いた場所 / エクスプローラーで見た場所
```

- **スキャン**: `FindFirstFileEx`（大きなまとめ読み）を 8 スレッドで並列に実行します。ネットワーク越しの列挙は待ち時間が大半なので、並列化がよく効きます。260 文字を超える長いパスにも対応しています
- **検索**: 入力した語がすべて「自分の名前か親フォルダの名前」に含まれ、少なくとも 1 語は自分の名前に含まれるものを表示します。名前の先頭や区切り位置での一致、フォルダであること、浅い階層、最近の更新、よく使うこと、ピン留めを加点して並べます
- **エクスプローラー連携**: Shell の COM API を使い、直前のウィンドウ（Windows 11 のタブを含む）を移動させます

## Mac で試す（デモ）

`demo/index.html` をブラウザ（Safari / Chrome）で開くだけで動きます。

- 架空の会社のファイルサーバー（約 3,800 件）で、Windows 版と同じ画面とキー操作を試せます
- 「自分のフォルダで試す」で Mac 上のフォルダを選ぶと、その中身で検索を試せます（ページ内だけで処理され、どこにも送信されません）
- 呼び出しは `⌘` + `K` か `/` です（Mac では `Ctrl` + `Option` + `Space` が入力ソースの切り替えに使われているため）
- 本物のエクスプローラーの代わりに、画面内の模型が移動します

検索エンジン部分（`demo/engine.js`）は `src/*.cs` を JavaScript に移植したもので、並び順の計算は Windows 版と同じです。

## 会社の PC で使う前に

- ファイルサーバーのスキャンはファイル名と更新日時を読むだけですが、件数が多いと最初のスキャンで一定の負荷がかかります。気になる場合は `ScanThreads` を小さくするか、情報システム部門に相談してください
- 自作の exe の実行が禁止されている環境もあります。社内ルールを確認してから使ってください
- インデックスには検索対象のファイル名が含まれます。PC の外には出ませんが、アクセス権のある範囲の名前が自分のプロファイルに保存されることになります

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「ホットキーを登録できませんでした」 | 他のアプリが同じキーを使っています。`Hotkey` を変更してください |
| `build.bat` で「csc.exe was not found」 | .NET Framework 4.x が無効になっています（通常の Windows 11 には入っています） |
| 検索結果に出てこない | `>` →「今すぐ再スキャン」を試してください。隠しフォルダは既定で対象外です（`SkipHidden`） |
| 動作がおかしい | `%LOCALAPPDATA%\FolderJump\log.txt` にエラーが記録されます |
