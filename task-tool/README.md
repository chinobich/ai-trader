# さくっとタスク

市役所PCなど、インターネットや外部サービスが使えない環境向けのタスク管理ツールです。
**HTMLファイル1つだけ**で動き、インストール不要・通信なし。

## 使い方

1. `index.html` をデスクトップや自分のフォルダに置く
2. Edge（または Chrome）で開く（ダブルクリック、またはブラウザにドラッグ）
3. 開いたページを「お気に入り」に登録しておくと、毎朝すぐ開けます

基本は **「書いて Enter」だけ**。日付などは文章から自動で読み取ります。

| 書き方の例 | 読み取られる内容 |
|---|---|
| `明日 財政課に電話` | 期限：明日 |
| `金曜まで 資料作成！` | 期限：今週金曜 ＋ 急ぎ |
| `10/15 議会の想定問答` / `15日 支払い` | 期限：指定日 |
| `今週中` `来週水曜` `月末` `3日後` | ざっくりした期限 |
| `@総務課 照会の回答待ち` | 「待ち」リストへ（相手つき・経過日数を表示） |
| `地区説明会 11/8` | 付属作業（周知・会場手配・資料準備…）を期限から逆算して自動追加 |
| `毎週月曜 定例会議の資料準備` | 繰り返し（完了すると次回分を自動追加） |
| `いつか 共有フォルダの整理` | 「いつか」リストへ |
| `毎年10月15日 次年度予算要求の提出` | 毎年の繰り返し（完了すると翌年分を自動追加） |

メールやメモから **複数行をまとめて貼り付け** ると、1行ずつタスクになります（先頭の「・」「1.」などは自動で除去）。

## 毎日の流れ

1. **朝の整理**（毎朝最初に開いたとき自動で表示／`O`キー）
   期限切れと、7日以上の返事待ちを1件ずつ「今日・明日・来週・いつか・終わった・やらない」にキー1つで振り分けます。
2. **今日の3つ**
   期限・急ぎ・付属作業の逆算から「今日やる3つ」を提案します。× で外して候補から入れ替えられます。決めた3つは画面上部に固定表示され、集中モードもこの3つから始まります。
3. **書き出す**：思いついたら入力欄へ。照会メールは本文ごと貼り付けてOK（下記）。
4. **ふり返り**（17時以降に案内／`R`キー）
   今日やったことの確認、やり残しを明日へ回す、日報のコピー（実施事項・明日の予定・返事待ち）が1画面でできます。
5. **印刷**（`P`キー）：今日の3つ・今日・1週間以内・返事待ちを、チェック欄つきのA4リストで印刷します。

## メール・照会文書の貼り付け

メール本文をそのまま貼り付けると、1件のタスクにまとめます。
- 件名（なければ「〜について」「〜の照会」などの行）→ タスク名
- 「回答期限：10月20日（火）」「締切：」などの行 → 期限
- 「回答先：総務課 行政係」「担当：」などの行 → 相手
- 本文全体 → メモに保存
- 「照会」などの場合は付属作業（内容確認・データ照会・回答案作成・決裁）を期限から逆算して追加

1行ずつ別のタスクにしたいときは、入力欄の下の「1行ずつ追加にする」を押してください。

## 自動整理（書き出した内容の分析）

AIは使わず、ファイルの中に入っている「市役所業務向けのルール」で分析します。通信は一切しません。

- **カテゴリ分け**：業務改革・DX／議会／予算・経理／契約・発注／照会・調査／文書・決裁／広報／イベント／会議／窓口／連絡／庶務／資料作成 の13分類に自動で振り分け
- **学習**：カテゴリを手で直すと、同じ言葉を含むタスクは次から自動でその分類になります（設定からリセット可）
- **関連まとめ**：「地区説明会」「財政課」など同じ言葉を含むタスクを1つのまとまりに。並べ方を「関連ごと」にすると、まとまりごとに表示
- **付属作業の自動追加**：「説明会」「会議」「議会」「出張」「契約」などを書くと、付きものの作業を親タスクの期限から逆算して追加
  （例：`地区説明会 11/8` → 開催案内・周知、会場・備品の手配、当日資料・名簿の準備、役割分担の共有、実施報告）
  - 業務改革課向けに、ヒアリング／業務量調査・棚卸／RPA・AI・ツール導入／業務フロー・BPR／計画策定／電子申請／研修会・勉強会／推進本部・庁議 のテンプレートを用意しています
  - 逆算した日が土日に当たる場合は平日にずらします（祝日は未対応）
  - 親の期限を変えると、付属作業の期限も自動で計算し直します
  - テンプレートは「設定 → 付属作業のテンプレートを編集」で、自分の課の仕事に合わせて自由に書き換えられます
  - 自動で追加せず「提案だけ」にもできます
- **重複チェック**：よく似たタスクがすでにあれば「1つにまとめる」を提案

追加した直後に「整理しました」カードが出て、分類・関連・付属作業（チェックを外せば取り消し）を確認できます。

## デザイン

「頭の中のモヤが晴れていく」がテーマです。背景は霧のかかった空で、今日のタスクを片付けるほど霧が晴れて青空になります（ダークモードは夜霧と星空）。右上の「頭の中の空模様」が モヤ → うす曇り → 晴れ間 → 快晴 と変わります。
動きが重い場合は「設定 → 軽量表示」をオンにしてください。

## 年間スケジュール

「設定 → 年間スケジュールを登録」で、毎年決まった時期の仕事（議会対応・予算要求・業務量調査など）を一括で繰り返しタスクにできます。
業務改革課の一般的な流れを例として入れてあるので、**月日と内容を自分の自治体に合わせて書き換えてから**登録してください。46日以上先のものは「先の予定」にたたんで表示します。

## 主な機能

- **やること**：期限切れ / 今日 / 明日 / 今週 / 来週 / それ以降 / 日付なし に自動で整理
- **期限切れの仕切り直し**：「ぜんぶ今日へ」「明日へ」でまとめて移動
- **待ち**：相手の返事待ちを分けて管理。1週間たつと「そろそろ確認を」と表示
- **集中モード**（`F`）：今やる1件だけを大きく表示。15/25/50分タイマー付き
- **完了の記録**：日付ごとに残り、「今日／今週の実績をコピー」で日報・週報に貼り付け可能
- **元に戻す**：完了・削除・移動はすぐ下の通知、または `Ctrl+Z` で取り消し
- ライト／ダークテーマ、キーボード操作（`?` で一覧表示）

## データの保存について

- データは **そのPCのブラウザ内（localStorage）** に保存されます。外部には一切送信しません。
- ブラウザの閲覧データ削除、PCの入れ替え、プロファイルが毎回リセットされる環境では消えることがあります。
  左下の「バックアップ」から **週1回程度ファイルに書き出し** ておくと安心です（設定画面から読み込みで復元できます）。
- 別のPCとは同期されません。移行するときはバックアップファイルを読み込んでください。
- `index.html` を別のフォルダへ移動・更新しても、同じブラウザで開けばデータはそのまま使えます。

> 自作ツールの利用可否は所属団体の情報セキュリティポリシーに従ってください。
> このツールは外部通信・外部ライブラリを一切使用していません（ファイル内のコードですべて完結）。

## 動作環境

Microsoft Edge / Google Chrome（最新版推奨）
